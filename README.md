## With the explosion of digital news and social media content, misinformation spreads rapidly, leading to misinformed public opinion. Traditional fact-checking methods are manual and time-consuming. Additionally, media bias in news articles can subtly influence readers’ perspectives. 

# Key problems this project aims to address: 
1. Real-time detection of misinformation in news articles, social media posts, and other 
online content. 
 
2. Analysis of potential bias in media reporting across multiple sources. 
 
3. Providing context-aware, verifiable answers to queries using trustworthy references.
